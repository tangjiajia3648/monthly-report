# 数字化月报演示模板

此仓库用于展示数字化部门月报原型。页面含模拟成果、使用量、需求和人员数据，不用于实际业绩汇报。

## 查看

启用 GitHub Pages 后，访问仓库设置中显示的站点地址。

## 发布设置

在仓库 Settings → Pages 中选择：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)

首页文件为 `index.html`，无需安装依赖或运行构建命令。

## 更新

用新生成的 `index.html` 替换当前文件并提交。页面内临时修改的图表数据不会保存到仓库。

## 访问范围

这是公开演示页面。正式部门数据需按公司的访问权限要求处理。
